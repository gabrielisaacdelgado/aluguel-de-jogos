🚀 Desenvolvi o AluGames, um projeto incrível de lógica de programação onde criei um sistema interativo de aluguel de jogos! A ideia é bem legal: temos uma galeria de jogos e, ao clicar em cada um deles, conseguimos alternar entre "Alugar" e "Devolver" de forma dinâmica.

O projeto trabalha com manipulação do DOM 🎯, onde conseguimos recuperar elementos HTML através do JavaScript, modificar classes CSS para criar efeitos visuais (como deixar a imagem opaca quando alugada) e alterar o texto dos botões em tempo real. Utilizamos condicionais (if/else) para verificar o estado atual do jogo usando a propriedade classList.contains(), e depois adicionamos ou removemos classes CSS conforme necessário. É uma excelente prática para entender como a lógica de programação funciona na prática! 💡

🛠️ Tecnologias e Ferramentas Utilizadas:
- HTML5 - Estrutura e semântica da página
- CSS3 - Estilização e efeitos visuais
- JavaScript (ES6+) - Lógica de programação e manipulação do DOM
- Visual Studio Code - Editor de código
- Git & GitHub - Controle de versão
